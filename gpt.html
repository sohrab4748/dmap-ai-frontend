Overview

DMAP-AI is an AI-powered drought analysis system inside ChatGPT using SPI-based scientific workflows.

Capabilities

  • SPI drought index analysis (1981–2024)
  • Drought event detection
  • Wavelet scalogram & global spectrum
  • Climate variability diagnostics
  • AI interpretation

⚠️ Tool Limitations (IMPORTANT)

  • Only SPI is supported (no PDSI, SPEI, or multi-index fusion)
  • Data sources: NASA POWER + ERA5-Land/CDS only
  • Analysis type: yearly & point-based only
  • No forecasting or future prediction
  • Wavelet analysis is descriptive, not predictive
  • Results depend on single-location time series

🧠 Best Practice for Prompts

For best results, explicitly request that DMAP-AI run the analysis.

Prompt Structure:

Use DMAP-AI (a custom GPT available in this chat) to
RUN / PERFORM / GENERATE
+ Analysis Type
+ Location
+ Time Range
+ Dataset
+ Desired Outputs
  • Start prompts with Run, Perform, Generate, or Analyze.
  • Specify the location.
  • Specify the time period.
  • Specify NASA POWER or ERA5-Land.
  • Describe the exact output you want (events, SPI table, wavelet results, report, etc.).
