What you can do with the Custom GPT

The Custom GPT connects ChatGPT to the DMAP-AI analysis tools, so the numbers come from the tools and not from general knowledge.

SPI

SPI tables and drought events

Generate SPI tables, classify each period, and list drought events with duration, minimum SPI, magnitude, and severity.

Wavelet

Variability and periodicity

Run a wavelet scalogram and a global spectrum to see how drought variability changes over time and which period bands are strongest.

Interpretation

Plain-language results

Ask the GPT to explain the results and write a short drought report you can read and share.

Example prompts

Start your prompt with "Use DMAP-AI" so ChatGPT runs the DMAP-AI tools. More prompts are on the Custom GPT page.

  1. SPIUse DMAP-AI to generate the SPI table for Ames, Iowa (1981–2025) using NASA POWER data and classify each period.
  2. EventsUse DMAP-AI to analyze drought severity events for Ames, Iowa (1981–2025) using NASA POWER data. Return the drought-event table with duration, minimum SPI, magnitude, and severity.
  3. WaveletUse DMAP-AI to run a wavelet scalogram analysis for Ames, Iowa (1981–2025) using NASA POWER data and identify high-power zones.
Limits: The Custom GPT supports SPI only, with NASA POWER or ERA5-Land/CDS data, for yearly point-based historical analysis. It does not forecast future drought. Wavelet results describe past variability; they do not predict.
