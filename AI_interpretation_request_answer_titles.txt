DMAP-AI Research Free Version — AI Interpretation Request/Answer Titles
=======================================================================

General rule
------------
The free Research Version sends ONE selected chart per AI request. The user must choose one chart only.

Every AI request sends these top-level request titles/sections:
1. mode
2. selected_chart_id
3. selected_chart_label
4. general_context
5. category_context
6. chart_context
7. output_contract

Always-sent general_context fields
----------------------------------
- platform
- version
- analysis_type
- drought_index
- drought_index_label
- location
- time_scale
- time_period
- baseline
- data_source
- units
- drought_threshold

Always-sent category_context fields
-----------------------------------
Only the ACTIVE category method is sent to AI. We do NOT send all category systems.

- selected_method
- selected_method_label
- note
- threshold_reference
- severity_threshold_for_events
- row_category_source

Category methods:
- classic: Classic SPI thresholds
- usdm: USDM-style SPI/SPEI ranges
- quantile: Percentile bands (statistical)
- kmeans: AI/ML – k-means clusters

The SPI table rows sent to AI include the category label produced by the active selected method.

Recommended prompt strategy used now
------------------------------------
The frontend sends a clean structured JSON request to the backend.
The backend builds the Gemini prompt using:
- a fixed system instruction for DMAP-AI drought/climate interpretation
- the selected chart label
- chart-specific output titles
- general_context
- category_context
- chart_context
- chart-specific interpretation limits

This is better than the older frontend prompt because:
- the Gemini API key stays hidden in the backend
- only one selected chart is interpreted in the free version
- output headings change by chart type
- the active drought-category method is explicit
- category systems are not mixed
- debug JSON is not printed to the browser console
