What can I do in the Research Free Version?

You can run point-based historical SPI analysis using NASA POWER or ERA5-Land/CDS, review tables and charts, save SPI runs, and request limited AI interpretation.

What does SPI mean?

SPI is the Standardized Precipitation Index. Negative values indicate drier-than-normal conditions, positive values indicate wetter-than-normal conditions, and values near zero are close to normal.

Which drought category is used in the AI explanation?

The AI receives only the active category method selected in the table, such as Classic SPI thresholds or USDM-style labels. It does not mix all category systems.

Why can I select only one chart for AI interpretation?

The free workflow is chart-specific. Selecting one chart keeps the explanation focused, reduces confusion, and helps manage the daily AI request limit.

What does drought severity mean?

Drought severity summarizes drought events below the selected SPI threshold. Magnitude is the accumulated drought deficit below that threshold, not wetness magnitude.

What does the wavelet chart show?

The wavelet scalogram shows how SPI variability changes over time and period. Strong power means stronger fluctuation at that time scale, but it does not prove causality or forecast future drought by itself.

Why do I have only 3 AI requests per day?

The Research Free Version allows limited daily AI interpretation while advanced AI limits and paid research features are being developed.

What does the Export tab do?

The Export tab lets you create one ZIP package containing selected tables, chart images, and the full current-run JSON. Tables are saved as CSV files, chart images are saved as PNG files, and the JSON is saved as a JSON file.

Which items can I include in the ZIP package?

You can select SPI tables, drought-event tables, precipitation aggregation tables, source precipitation data, SPI charts, anomaly charts, drought-severity charts, wavelet charts, copula diagnostics, and the full JSON context.

Why are some Wavelet or Copula exports missing?

Wavelet and Copula outputs are included only after those analyses have been generated in the app. Open the Wavelet tab to calculate the scalogram, global spectrum, and coherence. Click Compute Copula to calculate copula diagnostics. After each step is generated, those results are added to the full current-run JSON and become available for Copy JSON and Export.

When are Wavelet and Copula results added to JSON?

The full JSON is updated as the current run grows. After the SPI run, the JSON contains rainfall, aggregation, SPI, categories, and severity. After opening the Wavelet tab, wavelet blocks are added. After clicking Compute Copula, the copula block, including U/V pseudo-observations, is added.

How is source precipitation saved in the export?

Source precipitation is exported as a vertical CSV. The first rows contain metadata such as start date, end date, time step, units, and record count. After that, the file contains Date and Data columns.
